01｜交付成果與必要規格

交付 asm-prog-assignment/merge.S，唯一全域入口 array_sort。函式直接修改呼叫者提供的原始陣列，返回型別為 void，不需另交報告。C 檔是呼叫與驗證程式，不是排序解答。

void array_sort(int32_t *array, uint32_t size);
項目規格／實作對應
輸入a0＝array 位址；a1＝size，範圍 0～128。
元素完整 int32_t：−2147483648～2147483647，含負數、0、重複與全相等。
輸出原陣列升序；每個值及其出現次數不變。
邊界size＝0 不得讀寫陣列元素；size＝1 已排序。
指定演算法必須使用 Merge Sort；穩定性不要求，此實作遇相等先取左側。
02｜分割、遞迴、合併與回寫
長度 < 2？直接返回
mid = left + ((right − left) >> 1)半開區間 [left, right)
遞迴排序左右兩半[left, mid) 與 [mid, right)
合併 → buffer → array先收集全部元素，再回寫原陣列

範例：[3, −1, 3, 0] → [3, −1]／[3, 0] → [−1, 3]／[0, 3] → [−1, 0, 3, 3]。暫存區可避免尚未讀取的元素被提前覆蓋。

指標範圍角色
i / t0left ≤ i < mid左半下一元素
j / t1mid ≤ j < right右半下一元素
k / t2left ≤ k < right暫存區下一寫入位置

合併期間 buffer[left:k] 已排序，且恰好包含左右兩半已取出的元素。任一半耗盡後，複製另一半的剩餘元素；最後將 buffer[left:right] 寫回 array[left:right]。

時間複雜度 O(n log n)；合併工作區 512 bytes，另有 O(log n) 遞迴 frame。

03｜有號比較與記憶體位址

元素大小以 blt t5, t4, .Ltake_right 判斷「右值 < 左值」。負數的最高位元為 1，仍必須以有號方式比較。不要把元素相減後以差值正負判斷，因為 INT32_MIN 與 INT32_MAX 相減可能溢位。

slli t3, t0, 2    # index × 4 bytes
add  t3, s0, t3   # array + byte offset
lw   t4, 0(t3)    # 讀取 32-bit 元素
blt  t5, t4, .Ltake_right  # 有號元素比較

bgeu 與 bltu 用在非負的索引、長度與區間邊界；blt 用在有號元素。兩者用途不同。

位址公式：array[index] 位址＝array base＋4×index。合法索引 0～127，最後一個元素起始偏移 508 bytes。輸入須自然對齊。

04｜ABI、stack frame 與資源限制
frame配置
array_sort：544 bytes0～511：共享 buffer；512～527：未使用；528：s1；532：s0；536：ra；540～543：padding。
.Lmerge_sort：48 bytes20：s5；24：s4；28：s3；32：s2；36：s1；40：s0；44：ra；0～19：未使用。

544 與 48 均為 16 的倍數；入口 sp 已對齊時，每層分配後仍維持 16-byte 對齊。所有返回路徑先恢復保存的暫存器，再釋放 frame。

n＝128 最深呼叫鏈為 128→64→32→16→8→4→2→1，共 8 層 helper。此函式額外 stack 峰值為 544＋8×48＝928 bytes，小於 8 KiB；512-byte buffer 僅配置一次，所有遞迴層共用。

原始註解釐清：helper 實際使用 s0～s5，並已保存／恢復；s5 在目前運算中未使用，但仍保存／還原。原始英文「helper only caller-saved」描述不精確，下方來源視窗保留附件原文。

共同限制本頁解讀
RV32I / ILP32無 mul、div、rem；mv、li、j、ret 為偽指令，可展開成 RV32I。
符號／對齊.global array_sort；.align 2 代表 2²＝4-byte 對齊；.L 標籤為私有 helper。
來源 ≤256 KiB此附件來源：6027 bytes。
程式與靜態資料.text+.rodata ≤4 KiB；.data+.bss ≤4 KiB；.rodata+.data+.bss ≤4 KiB。此來源未定義靜態 buffer，實際 section 大小需以組譯結果確認。
安全不修改 gp／tp；不用 heap；不依賴前處理器，不使用 .include／.incbin。
