01｜項目一：32-bit有號整數陣列排序

本分頁功能與目的介紹：640個中文字

這一頁的主要目的，是讓你看懂第一題從規格到程式的完整解答。作業要求把零到一百二十八個有號三十二位元整數排成升序，結果寫回原本陣列，而且每個值與出現次數都必須保留。指定的方法是合併排序，因此不能只用另一種演算法得到相同結果。頁面先說明輸入位址與元素數如何透過暫存器傳入，再介紹分割左右兩半、分別排序、合併到暫存區以及寫回原陣列的流程，讓每個步驟都有明確目的。

多視窗區把左側的Ｃ呼叫者和右側的組合語言實作放在一起。左側負責建立陣列、呼叫排序以及檢查升序，右側才負責真正的合併排序。點選主題或程式行，可以看到相關位置反白及下方說明。這種對照可以幫助你理解跨語言呼叫，不會把驗證程式誤當成排序演算法。程式原文保留，複製時可以取得原始内容，便於回到課程環境繼續查看。

逐步示範區讓你輸入陣列，觀察原陣列與共享暫存區的不同狀態。分割時只是改變區間，合併時先填暫存區，回寫時才更新原陣列。透過上一步、下一步及滑桿，可以把數值變化和指令位置連起來。建議先看四個元素的例子，再測空陣列、重複值、逆序與正負極值，避免一次看太多步驟而失去資料流的方向。

本頁特別解釋有號比較與索引比較的差別。元素可能是負數，應以有號分支比較；索引與長度則是非負的邊界數值。元素位址由索引乘四取得，暫存區避免提早覆蓋尚未讀取的元素。最後還會說明函式保存返回位址與暫存器，以及如何確認排序結果不只升序，也保留全部原值。

閱讀完成後，你應能回答三個問題：為什麼必須先完成左右兩半，為什麼不能直接覆蓋原陣列，以及Ｃ的驗證結果能證明哪些條件。頁面的動畫是教學模型，不能取代組合語言執行。真正驗收仍要在課程容器中測試目前儲存的解答，並核對提交版本。

02｜項目二：4×4數獨求解器

本分頁功能與目的介紹：620個中文字

這一頁用來詳解第二題四乘四數獨求解器。输入棋盤共有十六個三十二位元整數，依橫列順序排列。零代表空格，一到四代表不可改動的線索。題目保證輸入合法且至少有一解，輸出必須把空格填滿，使每一橫列、每一直行與每個二乘二宮格都各有一到四一次。若有多個解，符合所有條件的任何一個都能接受，不必與特定標準答案完全相同。

頁面以回溯搜尋介紹解法：先找第一個空格，再試一到四，檢查橫列、直行與宮格，合法才填入並繼續求解。若後面的格子無法完成，就清除這次試填，換下一個候選；若子層成功，就保留棋盤並向上返回。這個过程讓你理解搜尋不是盲目填數字，而是每一步都利用限制條件縮小選擇。

棋盤視窗會顯示原始線索、目前格子、候選值和受檢查的區域，也提供座標、記憶體偏移與活動搜尋層資訊。按上一個或下一個步驟，可以看見填值、拒絕與清零發生的時機。自動播放適合先觀察整體流程，滑桿則適合停在某次回溯仔細閱讀。已完成、單空格、少線索、全空與需要回溯的範例，能呈現不同的搜尋行為。

Ｃ與組合語言雙視窗說明分工。Ｃ先保存原始線索並呼叫求解器，組合語言直接修改工作棋盤，最後Ｃ檢查線索未變、數值範圍與三類约束。私有搜尋函式用成功或失敗旗標控制回溯，公開入口卻是沒有回傳值的函式，真正結果在棋盤記憶體中。這兩種回傳意義需要分清楚，才能看懂成功傳播與正常返回。

本頁還解釋索引如何得到列和欄、同欄位址為什麼相差十六位元組，以及宮格四個位置如何計算。每層搜尋保存自己處理的格子與候選，避免子呼叫破壞父層狀態。完成閱讀後，你應能自行檢查任一解是否保留線索，並說明失敗時為什麼一定要清零。教學模型的成功仍需與實際解答測試區分。

03｜共同開發規格：RV32I、ABI與資源限制

本分頁功能與目的介紹：633個中文字

這一頁集中說明兩題都必須遵守的共同開發規格。排序或數獨答案看起來正確，仍可能因使用錯誤指令、破壞呼叫者暫存器、超出記憶體範圍或容量過大而不符合要求。因此本頁的功能，是把「算出答案」之外的條件逐項具體化，協助你了解一份可以安全連結與呼叫的組合語言函式應如何設計。

首先介紹基本指令集合與呼叫約定。兩題限定使用基本三十二位元整數指令與指定資料模型，不能依賴乘法、除法或餘數等擴充。索引乘四可以用左移，數獨列欄可用位移與遮罩取得。公開入口必須使用指定符號，輔助標籤保持私有。參數暫存器、返回位址和保存型暫存器各有不同責任，不能因某次範例剛好成功，就忽略跨呼叫的狀態保存。

互動模型會讓你觀察配置堆疊、保存返回位址、呼叫子函式、還原狀態與返回的順序。也可以用錯誤情境比較沒有還原暫存器或對齊錯誤時會發生什麼問題。這些模型主要用來理解規則，不是執行真正處理器，也不會自動證明解答通過正式安全測試。原始組合語言視窗仍可用於核對實際保存位置與指令。

資源計算區可以輸入來源檔大小、各區段大小、入口空間、每層遞迴空間與層數，觀察是否超過規定。排序的工作區只配置一次，數獨每層保留少量狀態；兩者的額外堆疊峰值可以由來源推導。來源檔大小不能代替組譯後的機器碼大小，程式、唯讀資料與靜態資料的合計限制也要分別核對，不能只看單一區段。

記憶體工具則示範範圍與自然對齊。例如合法區域總共有多少位元組、一次讀取幾個位元組、起始偏移在哪裡，都影響是否越界。讀取前先檢查上界，是兩題共同的重要做法。閱讀後應能自行畫出堆疊配置，確認返回時還原入口狀態，並知道哪些證據必須從組譯產物或實際執行取得，而不是只靠來源註解。

五份程式：原文與作業規格對照

程式01｜merge(4).c

程式角色與符合規格的說明：630個中文字

這份Ｃ程式是第一題的呼叫者與升序驗證器，不是合併排序的解答本體。它包含設定檔與輸出工具，宣告外部排序函式，再於主函式建立陣列、呼叫組合語言排序，最後檢查排序結果。作業真正要繳交的排序檔是組合語言來源；這份Ｃ的作用，是展示呼叫介面如何使用，以及提供一部分結果檢查。

陣列初始内容由設定檔的巨集提供，元素數也由對應巨集給定。Ｃ把陣列首位址和元素數傳給排序函式，在指定呼叫約定下對應到參數暫存器。陣列沒有被複製成另一份函式輸入，組合語言直接寫回這個記憶體區域。因此排序函式的回傳型別可以是沒有值，主函式仍能從原本陣列看到完成結果。這符合題目要求修改呼叫者提供的原始記憶體。

驗證函式用迴圈檢查相鄰元素，發現前者大於後者就回傳失敗，全部檢查完則回傳成功。這個比较使用有號整數語意，因此能判斷負數和正數的升序。迴圈條件先確認下一格存在，再進行讀取；長度零或一時沒有相鄰元素可檢查，便直接成功。相等值也被接受，因為升序允許非遞減，不要求每格都嚴格變大。

這份驗證器有明確限制：它沒有保存原陣列的全部頻次，也沒有比較排序前後是否具有相同元素。若錯誤解答把所有元素改成零，仍可能通過升序檢查。此外，它不檢查組合語言使用的演算法、不直接監控越界，也不完整檢查保存型暫存器與堆疊狀態。因此它只對應升序要求，不能單獨證明整題滿分。

使用時應把它放在課程既有建置架構下，保留設定檔與輸出工具依賴，不要把這個檔案當成獨立排序函式。若要加強驗證，可另存排序前的值與次數，排序後重新統計比對，並由正式工具確認呼叫約定及記憶體安全。首頁提供完整原文供檢視與下載，不修改附件內容，也不把Ｃ的成功回傳冒充完整批改結果。

程式02｜merge(6).S

程式角色與符合規格的說明：608個中文字

這份組合語言是第一題的正式解答，入口為指定的陣列排序函式。它接收原陣列位址與元素數，以遞迴合併排序完成升序，並把結果寫回原陣列。來源公開唯一指定入口，輔助程式使用私有標籤；位移、分支、讀寫與加減都可以在基本整數指令集合中完成，不需要乘法或除法擴充。

入口先配置堆疊並保存返回位址與需要的保存型暫存器。工作區有五百一十二位元組，可以容納一百二十八個整數，所有遞迴層共用，不是每層重新配置一個大陣列。長度小於二時直接走返回路徑，不讀寫陣列元素，因此空陣列與單元素符合邊界要求。堆疊讀寫仍會發生，但題目禁止的是空陣列的元素存取，兩者不能混淆。

輔助函式使用左含右不含的區間，先計算中點，遞迴完成左半與右半，再把兩個已排序區間合併。左右各有一個讀取游標，工作區有一個寫入游標。每次先檢查邊界，再讀取左右值，用有號比較選較小值。相等時取左，但右值仍會在之後搬入，所以重複值次數保留。若一半耗盡，就把另一半剩餘元素依序補上。

合併完成才將工作區寫回原陣列，避免提前覆蓋尚未讀取的值。索引乘四以左移取得，讀寫位址保持自然對齊。每層保存自己的區間與返回位址，子呼叫完成後能恢復父層狀態；出口也恢復被使用的保存型暫存器與堆疊指標。依来源推導，最大長度的額外堆疊峰值小於題目限制。

這份程式主要對應指定合併排序、完整有號範圍、升序、元素頻次不變、原陣列输出與呼叫約定要求。來源註解中說輔助程式只用呼叫者保存暫存器並不精確，實際也使用已保存還原的保存型暫存器。原文保留時要以指令為準。正式驗收仍需組譯後檢查容量及執行安全，不能只憑閱讀來源宣布全部測試通過。

# void array_sort(int32_t *array, uint32_t size)
#
# a0: Pointer to the first signed 32-bit array element.
# a1: Number of elements (0 through 128).
#
# Sort the array in ascending SIGNED order using merge sort.
# The final sorted values are written back into the input array.
# A 128-element temporary buffer is allocated on the stack.
#
# Calling convention:
#   - s0 and s1 are callee-saved and are restored before returning.
#   - The stack remains 16-byte aligned at every function call.
#   - All helper routines use caller-saved registers only.
#
# Stack frame (544 bytes):
#   0..511   Temporary merge buffer (128 * 4 bytes)
#   528      Saved s1 (buffer base)
#   532      Saved s0 (array base)
#   536      Saved ra
#   540      Unused padding
array_sort:
        addi    sp, sp, -544       # Reserve temporary storage and saved-register slots.
        sw      ra, 536(sp)        # Preserve the return address.
        sw      s0, 532(sp)        # Preserve the caller's s0.
        sw      s1, 528(sp)        # Preserve the caller's s1.
        mv      s0, a0             # Keep the original array base in s0.
        mv      s1, sp             # Use the beginning of the frame as the buffer.

        li      t0, 2              # Arrays with fewer than two elements are sorted.
        bltu    a1, t0, .Lsort_done

        # Recursive helper arguments:
        #   a0 = array base, a1 = temporary buffer base
        #   a2 = left index (inclusive), a3 = right index (exclusive)
        mv      a3, a1             # Preserve size before replacing a1 with buffer.
        mv      a1, s1             # Temporary buffer pointer.
        mv      a2, zero           # Left boundary = 0.
        mv      a0, s0             # Original array pointer.
        jal     ra, .Lmerge_sort

        lw      s1, 528(sp)        # Restore callee-saved registers.
        lw      s0, 532(sp)
        lw      ra, 536(sp)
        addi    sp, sp, 544        # Release the temporary buffer and frame.
        ret

# Recursive merge sort over the half-open range [left, right).
# Arguments: a0=array, a1=buffer, a2=left, a3=right.
# This routine saves its working state because recursive calls overwrite
# caller-saved argument registers.
.Lmerge_sort:
        addi    sp, sp, -48        # Allocate an aligned recursive stack frame.
        sw      ra, 44(sp)
        sw      s0, 40(sp)
        sw      s1, 36(sp)
        sw      s2, 32(sp)
        sw      s3, 28(sp)
        sw      s4, 24(sp)
        sw      s5, 20(sp)

        mv      s1, a1             # Buffer base.
        mv      s2, a2             # Left index.
        mv      s3, a3             # Right index (exclusive).

        sub     t0, s3, s2         # Number of elements in the current range.
        li      t1, 2
        bltu    t0, t1, .Lmerge_return # Length 0 or 1: already sorted.

        srli    t0, t0, 1          # Half the range length, rounded down.
        add     s4, s2, t0         # Midpoint = left + (right-left)/2.

        # Sort the left half [left, mid).
        mv      a0, s0
        mv      a1, s1
        mv      a2, s2
        mv      a3, s4
        jal     ra, .Lmerge_sort

        # Sort the right half [mid, right).
        mv      a0, s0
        mv      a1, s1
        mv      a2, s4
        mv      a3, s3
        jal     ra, .Lmerge_sort

        # Merge two sorted halves into buffer[left:right].
        mv      t0, s2             # i: current index in left half.
        mv      t1, s4             # j: current index in right half.
        mv      t2, s2             # k: destination index in buffer.

.Lmerge_compare:
        bgeu    t0, s4, .Lcopy_right # Left half exhausted.
        bgeu    t1, s3, .Lcopy_left  # Right half exhausted.
        slli    t3, t0, 2          # Convert left element index to byte offset.
        add     t3, s0, t3
        lw      t4, 0(t3)          # Load signed left value.
        slli    t3, t1, 2
        add     t3, s0, t3
        lw      t5, 0(t3)          # Load signed right value.
        blt     t5, t4, .Ltake_right # Signed comparison: right < left.

        # Left value <= right value; take left to preserve stable order.
        slli    t3, t2, 2
        add     t3, s1, t3
        sw      t4, 0(t3)
        addi    t0, t0, 1
        addi    t2, t2, 1
        j       .Lmerge_compare

.Ltake_right:
        slli    t3, t2, 2
        add     t3, s1, t3
        sw      t5, 0(t3)
        addi    t1, t1, 1
        addi    t2, t2, 1
        j       .Lmerge_compare

.Lcopy_left:
        bgeu    t0, s4, .Lcopy_back # No remaining left elements.
        slli    t3, t0, 2
        add     t3, s0, t3
        lw      t4, 0(t3)
        slli    t3, t2, 2
        add     t3, s1, t3
        sw      t4, 0(t3)
        addi    t0, t0, 1
        addi    t2, t2, 1
        j       .Lcopy_left

.Lcopy_right:

        slli    t3, t1, 2
        add     t3, s0, t3
        lw      t4, 0(t3)
        slli    t3, t2, 2
        add     t3, s1, t3
        sw      t4, 0(t3)
        addi    t1, t1, 1
        addi    t2, t2, 1
        j       .Lcopy_right

.Lcopy_back:
        mv      t0, s2             # Copy merged range back into input array.
.Lcopy_back_loop:
        bgeu    t0, s3, .Lmerge_return
        slli    t1, t0, 2
        add     t2, s1, t1
        lw      t3, 0(t2)          # Read merged value from temporary buffer.
        add     t2, s0, t1
        sw      t3, 0(t2)          # Overwrite original array element.
        addi    t0, t0, 1
        j       .Lcopy_back_loop

.Lmerge_return:
        lw      s5, 20(sp)
        lw      s4, 24(sp)
        lw      s3, 28(sp)
        lw      s2, 32(sp)
        lw      s1, 36(sp)
        lw      s0, 40(sp)
        lw      ra, 44(sp)
        addi    sp, sp, 48
        ret

#include "sudoku_config.h"

extern void sudoku_solver(int *arr_ptr);

int sudoku_verifier(int *arr_ptr, const int *clues) {
    // Every non-zero input value is a fixed clue and must remain unchanged.
    for (int i = 0; i < 16; i++) {
        if (clues[i] != 0 && arr_ptr[i] != clues[i]) {
            return -1;
        }
    }

    // check each row and column
    for (int i = 0; i < 4; i++) {
        int row[5] = { 0 }, col[5] = { 0 };
        for (int j = 0; j < 4; j++) {
            int r = arr_ptr[4 * i + j];
            int c = arr_ptr[4 * j + i];

            if (r < 1 || r > 4 || row[r]) {
                return -1;
            }
            if (c < 1 || c > 4 || col[c]) {
                return -1;
            }

            row[r] = 1;
            col[c] = 1;
        }
    }

    // check each sub-block
    for (int bi = 0; bi < 2; bi++) {
        for (int bj = 0; bj < 2; bj++) {
            int seen[5] = { 0 };
            for (int i = 0; i < 2; i++) {
                for (int j = 0; j < 2; j++) {
                    int v = arr_ptr[(bi * 2 + i) * 4 + (bj * 2 + j)];
                    if (v < 1 || v > 4 || seen[v]) {
                        return -1;
                    }
                    seen[v] = 1;
                }
            }
        }
    }

    return 0;
}

int main(void) {
    const int clues[] = { SUDOKU_RANDOM_ARRAY };
    int arr[]          = { SUDOKU_RANDOM_ARRAY };
    sudoku_solver(arr);
    return sudoku_verifier(arr, clues);
}

每列分數必须是合法整數，不可超過上限，通過旗標也要與滿分條件一致；逐列上限總和和得分總和必須對上總分。只有总分一百分且全部列都通過，才印出本機全部通過。若未滿分，只顯示第一個失敗列、原因與有限長度的訊息，並以失敗狀態結束。

腳本退出时會刪除暫存結果，因此一般終端輸出不能提供完整四十三列紀錄。完整查核需要正式平台或助教提供的結果資料與提交版本。它主要對應測試流程、結果一致性與工具版本要求，不單獨證明來源內容或正式提交已完成。首頁保留原文供下載，使用時應放在課程倉庫並遵循工具安裝流程。

#!/usr/bin/env bash
# Local feedback only. Reads the two current assembly files without a commit.
set -euo pipefail

expected_digest='sha256:f0ff938b7c554c1d021d5e91e31dfcbaeb810b88892dec6c0c404fac530b42db'
repo_root="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd -P)"
error() { printf 'ERROR：%s\n' "$*" >&2; exit 2; }
trap 'error "測試工具遇到非預期錯誤（第 ${LINENO} 行）；請保留上方訊息並聯絡助教。"' ERR

[[ "$(uname -s)" == Linux && "$(uname -m)" == x86_64 && -f /.dockerenv ]] ||
    error '請在 Lab 0 的課程容器內執行。'
for executable in git sudo python3; do
    command -v "$executable" >/dev/null 2>&1 || error "找不到 $executable。"
done
[[ -x /opt/lab2-grader/grade-one && -f /opt/lab2-tools/lab2-tools-lock.json ]] ||
    error '本機測試工具尚未安裝，請先執行 ./setup-local-test.sh。'
[[ -d "$repo_root/.git" ]] || error '請在你自己的 Lab 2 作業 repo 內執行。'
[[ "$repo_root" == /home/ubuntu/workspace/* ]] || error '作業須位於課程容器的工作區。'

python3 - "$expected_digest" <<'PY' || error '批改工具版本與課程正式版本不符。'
import json, pathlib, sys
try:
    lock = json.loads(pathlib.Path('/opt/lab2-tools/lab2-tools-lock.json').read_text())
    if lock['grader_image'] != 'ghcr.io/computer-organization-at-ncku-ee/co-lab2-grader-v2@' + sys.argv[1]:
        raise ValueError('unexpected grader version')
except (OSError, ValueError, KeyError, TypeError):
    raise SystemExit(1)
PY

# HEAD is only a reproducible test seed. The grader reads saved working files.
commit="$(git -C "$repo_root" rev-parse --verify HEAD 2>/dev/null)" ||
    error '作業 repo 沒有可用的 commit。'
[[ "$commit" =~ ^[0-9a-f]{40}$ ]] || error '無法取得有效的測試種子。'

temporary="$(sudo mktemp -d /tmp/lab2-self-test.XXXXXXXX)" ||
    error '無法建立批改暫存資料夾。'
[[ "$temporary" =~ ^/tmp/lab2-self-test\.[A-Za-z0-9]{8}$ ]] ||
    error '批改暫存路徑異常。'
trap 'sudo rm -r -- "$temporary"' EXIT

printf '正在測試目前已儲存的兩份組合語言程式，請稍候。\n'
if ! sudo env \
    PATH='/opt/riscv-gnu-toolchain/bin:/usr/local/bin:/usr/bin:/bin' \
    LAB2_WORKER_USER=lab2worker \
    LAB2_GRADER_IMAGE_DIGEST="$expected_digest" \
    /opt/lab2-grader/grade-one \
    --submission "$repo_root" \
    --owner local \
    --commit "$commit" \
    --manifest lab2-v1 \
    --output-dir "$temporary" >/dev/null; then
    error '批改器執行失敗，請把上方訊息提供給助教。'
fi
sudo chown "$(id -u):$(id -g)" "$temporary" "$temporary/grade.json" "$temporary/audit.json" ||
    error '批改器未產生完整結果。'
chmod 0700 "$temporary"
chmod 0600 "$temporary/grade.json" "$temporary/audit.json"

if python3 - "$temporary/grade.json" "$temporary/audit.json" "$expected_digest" <<'PY'
import json, pathlib, sys
try:
    grade = json.loads(pathlib.Path(sys.argv[1]).read_text())
    audit = json.loads(pathlib.Path(sys.argv[2]).read_text())
    rows = grade['rows']
    expected_ids = ['C01', 'C02'] + [f'M{i:02d}' for i in range(1, 22)] + [f'S{i:02d}' for i in range(1, 21)]
    score = grade['score']
    valid = (
        grade['schema'] == 'ncku-co/lab2-grade/v1'
        and audit['schema'] == 'ncku-co/lab2-audit/v1'
        and audit['infrastructure_error'] is False
        and audit['grader']['image_digest'] == sys.argv[3]
        and grade['manifest']['version'] == 'lab2-v1'
        and [row['id'] for row in rows] == expected_ids
        and sum(row['max_score'] for row in rows) == 100
        and sum(row['score'] for row in rows) == score
        and grade['max_score'] == 100
        and type(score) is int and 0 <= score <= 100
        and all(
            type(row['score']) is int and type(row['max_score']) is int
            and 0 <= row['score'] <= row['max_score']
            and type(row['passed']) is bool
            and row['passed'] == (row['score'] == row['max_score'])
            for row in rows
        )
    )
    if not valid:
        raise ValueError('批改結果格式、配分或工具版本不符')
    if score == 100:
        if not all(row['passed'] for row in rows):
            raise ValueError('100 分結果仍含失敗測試列')
        print('PASS：本機測試全部通過（100/100）。')
    else:
        first = next(row for row in rows if not row['passed'])
        message = first['message'].replace('\n', ' ').replace('\r', ' ')[:240]
        print(f'FAIL：本機測試未全通過（{score}/100）。')
        print(f"第一項失敗：{first['id']} {first['reason']} — {message}")
        raise SystemExit(1)
except (OSError, KeyError, TypeError, ValueError, IndexError, StopIteration) as exc:
    print(f'ERROR：無法確認批改結果：{exc}', file=sys.stderr)
    raise SystemExit(2)
PY
then
    exit 0
else
    exit $?
fi
