01｜交付成果與必要規格

交付 asm-prog-assignment/sudoku.S，唯一全域入口 sudoku_solver。結果直接写回原棋盤，公開函式不回傳值。附件 C 是呼叫者與驗證程式，沒有 C 求解器本體。

void sudoku_solver(int32_t *board);
項目規格／實作對應
輸入a0＝16個 int32_t 的棋盤位址；row-major，board[row*4+col]。
數值0為空格，1～4為固定線索；輸入保證合法且至少一解。
輸出全部16格為1～4；每一橫列、直行、2×2宮格各有1～4一次。
固定線索原始非零格不可改動；只在找到的0格試填。
多解接受任一合法解，不要求指定唯一答案。
演算法未強制指定；這份來源使用遞迴 Backtracking。
02｜找空格、試候選、檢查與回溯
掃描0～15找第一個0；沒有空格就成功
依序試1、2、3、4；檢查橫列、直行與宮格
合法才填入，再遞迴處理剩餘空格
子層失敗：清0 → 試下一值；四值都失敗則返回0
子層成功：立即返回1，保留全部答案

每個活動 frame 負責一個空格。固定線索與父層已填值都被掃描跳過。成功只能在合法輸入與每次合法填入的前提下成立。

若 E 為空格數，搜尋樹候選分支最多4，粗略上界為 O(4E)；4×4每次掃描與限制檢查都是固定大小，stack 為 O(E)。實際剪枝通常大幅減少搜尋。

03｜索引、位址與三類約束
計算公式／指令
row / colrow=index>>2；col=index&3 → srli / andi。
格子位址board＋(index<<2)；索引0～15，偏移0～60 bytes。
橫列board＋(row<<4)，四次lw，每次地址＋4。
直行board＋(col<<2)，四次lw，每次地址＋16。
宮格起點row&~1、col&~1；因值為0～3，來源 andi 2 等價。
宮格四格起點地址＋0、4、16、20 bytes。

helper 先讀取、後判斷，只有合法才由搜尋層寫入。目標格仍為0，不會与候選1～4誤判相等。宮格檢查位於 .Lsudoku_valid 中，來源沒有獨立宮格標籤。

04｜ABI、stack frame 與共同資源限制
位置／暫存器用途
每層32 bytes0～11：未使用；12：s3；16：s2；20：s1；24：s0；28：ra。
s0 / s1 / s2 / s3棋盤指標／空格索引／候選值／格子地址；全數保存與恢復。
公開入口j尾跳，不另配置frame，不覆寫原始ra。
合法性helperleaf，只使用caller-saved暫存器，不配置frame。
最壞stack全空16格＋終止確認層＝17×32＝544 bytes；不含C呼叫端。
對齊入口4-byte對齊，sp全程16-byte對齊並恢復入口值。

RV32I／ILP32；不用mul/div/rem或其他擴充指令；不依賴C前處理器、不用.include／.incbin；兩題各自組譯連結；helper為私有符號，不修改gp／tp，無heap。

每份來源≤256 KiB；.text+.rodata≤4 KiB；.data+.bss≤4 KiB；.rodata+.data+.bss≤4 KiB；所有活動遞迴共用8 KiB stack。僅存取合法棋盤與自己配置的stack。附件 sudoku.S 為5791 bytes，未配置靜態資料，section實際容量仍以組譯結果確認。
