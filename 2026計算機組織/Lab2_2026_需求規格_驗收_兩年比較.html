先看這裡：要開發什麼？如何完成？

交付成果：兩個 RV32I 組合語言函式，修改呼叫者提供的原始記憶體，正確返回。正式解答為 merge.S 與 sudoku.S，不需另交報告。

  1. 項目一：32-bit 有號整數陣列排序
    • 檔案／入口：asm-prog-assignment/merge.S；void array_sort(int32_t *array, uint32_t size)。a0 為陣列位址，a1 為元素數。
    • 必要規格：size=0～128；涵蓋完整 int32_t 範圍、負數、0、重複值與全相等值；升序排序，全部原始元素與出現次數不變，結果寫回原陣列。size=0 不得讀寫陣列元素；不要求穩定排序。
    • 指定方法：必須使用 Merge Sort。建議先判斷長度≤1，再分割左右區間、各自排序、合併至暫存區、複製回原陣列；遞迴或 bottom-up 迭代皆可。
    • 實作方法：元素以 blt／bge 或 slt 做有號比較，不以相減判斷大小；索引乘4以 slli 計算。可配置最多128個元素、512 bytes 的合法暫存工作區，靜態資料或 stack 均須符合限制。
    • 驗收：測試長度0、1、127、128，正序／逆序、INT32_MIN／INT32_MAX、負數、重複與全相等；獨立確認升序及元素多重集合不變。
  2. 項目二：4×4 數獨求解器
    • 檔案／入口：asm-prog-assignment/sudoku.S；void sudoku_solver(int32_t *board)。a0 為16個 int32_t 的棋盤位址，row-major，board[row*4+col]。
    • 必要規格：0 是空格；1～4 是不可改動的線索。輸入保證合法且至少有一解；輸出16格皆為1～4，每一橫列、每一直行及每個2×2宮格各有1～4一次。多解接受任一合法解。
    • 建議方法：使用 Backtracking：找0 → 試1～4 → 檢查列／行／宮格 → 合法則填入並繼續搜尋 → 失敗才清0改試下一值 → 成功立即返回、保留答案。數獨未強制指定演算法。
    • 實作方法：以 index>>2 與 index&3 求 row／col；用 row&~1、col&~1 求宮格起點。規劃 helper 與遞迴 frame，保存返回位址及跨呼叫仍需使用的棋盤指標、格子索引與候選值。
    • 驗收：測試已完成、單空格、一般、少線索、全空及多解棋盤；獨立確認數值範圍、三類約束與原始線索不變。
  3. 共同開發規格：RV32I、ABI 與資源限制
    • 必要規格：RV32I／ILP32；不用 mul／div／rem 或其他擴充指令。不依賴 C 前處理器，不用 .include／.incbin；兩題獨立組譯與連結。各檔恰好定義指定的一個全域入口，入口4-byte對齊，helper 為私有符號。
    • 達成方法：先畫暫存器與 stack frame 配置；呼叫前保存 ra 及必要 caller-saved 狀態，使用 s0～s11 就保存並恢復；不修改 gp／tp；sp 全程16-byte對齊且返回時恢復入口值，所有返回路徑完整還原。
    • 容量與安全：每份來源≤256 KiB；.text+.rodata≤4 KiB；.data+.bss≤4 KiB；.rodata+.data+.bss≤4 KiB；所有活動遞迴層共用8 KiB stack。僅存取合法輸入、自己的靜態資料與配置的stack；自然對齊，無heap。

02｜Merge Sort 完整功能規格正式要求
  • size 為 uint32_t，0～128；特別涵蓋 0、1、127、128。
  • 元素為 signed int32_t，涵蓋 −2147483648～2147483647；負數、0、重複、全相等都要處理。
  • 必須 Merge Sort；不要求 stable sort。結果寫回原陣列，可用合法輔助工作區。
  • size=0 時 a0 合法且對齊，但不能存取任何元素。size=1 應保留原值。
  • 只操作 array[0]～array[size−1]；排序不能遺失或增加元素。
輸入： [3, -1, 2, -1]
輸出： [-1, -1, 2, 3]

元素必須使用有號比較，例如 blt/bge 或 slt，不要用 unsigned 比較負數，也不要用相減的正負判斷大小：極值相減可能溢位。索引和長度是非負數，可採 unsigned 比較。

來源：2026 §1.1、3.2、3.5；元素數量與值保存為排序正確性的驗證方式。

03｜排序實作分解與地址計算實作建議
  1. 長度 ≤1 返回。
  2. 分割左右區間，分別排序。
  3. 比較左右尚未取出的元素，把較小者寫入暫存。
  4. 補入另一側剩餘元素。
  5. 將暫存結果複製回原陣列。
sort_range(array, temp, left, right):  # 半開區間 [left,right)
    if right-left <= 1: return
    mid = left + ((right-left) >> 1)
    sort_range(array, temp, left, mid)
    sort_range(array, temp, mid, right)
    merge 兩側至 temp，並寫回 array[left:right]

半開區間是建議，不是規格；迭代 bottom-up 也可實作 Merge Sort。128 個 int32_t 暫存需要 512 bytes，可用合法 .bss 或有界 stack。避免每層重複配置完整大陣列。

# t0 = index；a0 = array，這是教學片段
slli t1, t0, 2
add  t1, a0, t1
lw   t2, 0(t1)

每元素 4 bytes，所以地址偏移為 index×4。合併不可提早覆蓋未讀元素。遞迴後仍需要的 array、temp、left、right、mid 必須保存。標準 Merge Sort 時間 O(n log n)、工作陣列 O(n)。

04｜4×4 Sudoku 輸入與輸出正式要求

16 個 int32_t，以 row-major 儲存。棋盤 4×4，宮格 2×2；0 是唯一空格，1～4 是固定線索。輸入保證合法且至少一解；不測非法或無解棋盤。

board[row*4 + col]
byte_offset = (row*4 + col)*4

輸入             一個合法輸出
2 4 0 0          2 4 1 3
3 1 0 2          3 1 4 2
0 3 0 4          1 3 2 4
0 2 3 1          4 2 3 1
  • 16 格皆為 1～4，不能殘留 0。
  • 每一橫列（row）、每一直行（column）、每個 2×2 宮格各含 1、2、3、4 一次。
  • 原始非零線索不得改動。
  • 多解時任一合法解可接受；搜尋演算法與順序不限。
  • 測試包含已完成、單一空格、少線索、全空與多解棋盤。

來源：2026 §3.3、3.5。上例解答為教學展示。

05｜回溯開發與成功保留答案實作建議
solve(board) -> bool:
    找第一個 0
    沒空格：return true
    for value in 1..4:
        if 同列、同行、同宮格皆允許:
            board[cell] = value
            if solve(board): return true
            board[cell] = 0
    return false

只有失敗才清 0！成功後立即一路返回，否則會把完成的解清掉。

內部 helper 可回傳 bool，但外部 sudoku_solver 仍是 void。wrapper 呼叫 helper 也要保存 ra。每層保存 board 指標、cell、候選值；a/t 暫存器不保證跨 call 保留。

row = index >> 2
col = index & 3
box_row = row & ~1
box_col = col & ~1

列檢查 board[row*4+k]，行檢查 board[k*4+col]，k=0..3；宮格檢查 (box_row+dr,box_col+dc)，dr、dc=0,1。此處 row、col、index 為非負數；乘 4 可用 slli、除 4 可用 srli，不需 mul/div。只找原本空格試填，避免改掉線索。

項目正式規則
指令RV32I／ILP32；不可用 mul/div/rem、RVC、浮點或其他擴充

保留 skeleton保留 .global、.type、.align、入口標籤；helper 私有

# 非 leaf 函式教學骨架，依實際需求增加保存空間
addi sp, sp, -16
sw ra, 12(sp)
sw s0, 8(sp)
mv s0, a0
call helper
lw s0, 8(sp)
lw ra, 12(sp)
addi sp, sp, 16

所有提前返回也要走正確 epilogue。每層遞迴需要獨立 frame。Leaf 若不呼叫其他函式、不改 s 暫存器，可無 frame。

限制同時成立；原始檔 bytes 不等於機器碼 bytes。無 heap，不能 malloc/free/new 或自行假設一塊未授權 RAM。僅可存取合法輸入、自己的 static data 和配置好的 stack。不可寫 text/rodata；lw/sw 4-byte 對齊，其他 load/store 也須自然對齊。

Runtime 載入 ELF、每個測試重置記憶體與暫存器、初始化 sp/gp/tp 與參數，直接啟動入口。不能靠上一測試的狀態。my_printf 只供 debug，共同支援 %c、%d、%s；call 後 a/t/ra 可能變動。
