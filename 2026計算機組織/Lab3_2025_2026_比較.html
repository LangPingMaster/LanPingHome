一張完整比較表｜相同、不同與證據不足
項目2025 要求／附件現況2026 要求差異與處理方式判定
目標與 CPU 架構單週期 CPU；37 條 RV32I單週期 CPU；37 條 RV32I相同 ISA 行為，以一個週期完成指令；IF/ID/EX/MEM/WB 不是五個週期。相同
指令範圍OP、OP-IMM、LOAD、STORE、BRANCH、JAL、JALR、LUI、AUIPC同樣九類、37 條不要求額外的 M-extension 乘除法與浮點硬體。相同
必做檔案數八個 .sv 模組九個 .v 模組不能只改副檔名；須遵守今年的模組及 port。不同
整合層CoreTop.sv 是核心；Top.sv 包含周邊Top.v 整合 CPU 與 IM/DM SRAM重新整合，不沿用去年的外層記憶體架構。不同
Decoder欄位擷取在 CoreTop/Controller獨立 Decoder.v將欄位擷取與控制產生分開。不同
opcode新 ZIP Controller 使用 instr[6:0]，7 bitsDecoder 輸出 inst[6:2]，5 bits例如 OP 的 0110011 改為 01100；不能拿 7-bit 常數比 5-bit 輸入。不同
func7ZIP 使用 instr[31:25]，7 bits介面僅 inst[30]，1 bit此 bit 只在適用指令中解讀；ADDI 的立即數 bit 30 不是 SUB 選擇。不同
分支比較獨立 BranchComp；BrUn/BrEq/BrLtALU 輸出分支條件 jump比較邏輯搬入 ALU；不是刪掉比較功能。不同
分支／跳躍加法簡報由 ALU 等路徑計算；ZIP 實際以獨立 assign 計算 targetJB_Unit.v 計算目標加法官方圖與學生實作要分開：新 ZIP 的 branch_target 不是由 alu_result 驅動。不同
Controllerinstr 與 BrEq/BrLt，輸出 alu_ctrl 等配合 Decoder、ALU jump 與新資料路徑保留解碼思路，依今年宣告重寫介面與控制。不同
PCreset=0，上升緣更新reset=0，上升緣更新正常規格相同；ZIP 額外 first_cycle 是學生實作，不是官方要求。相同
Resetrst_n，低有效非同步rst，低有效非同步名稱不同；今年還明訂 reset 期間 DM 寫入遮罩為 0。不同
RegFile32×32；兩讀一寫；讀非同步、寫上升緣相同x0 永遠為 0；讀取不依賴寫入 enable。相同
RegFile 陣列mem；舊階層 top.core.reg_file.memreg [31:0] registers [0:31];驗證依賴名稱；今年用 top.regfile.registers。不同
暫存器初始化32 個暫存器均為零均為零；明訂 x2 不可特設非零stack pointer 交由 runtime 初始化。相同
立即數ImmExt.sv，I/S/B/U/JImme_Ext.v，依 inst 內部判斷格式位元重組概念可沿用；B/J 低位補 0；U 低 12 位為 0；無 ImmSel port。相同
ALU 算術與比較ADD/SUB、AND/OR/XOR、位移、SLT/SLTU相同運算，另含分支條件輸出有號比較、無號比較及算術右移需正確。不同
Next PC 與寫回PC+4、branch、JAL、JALR相同 ISA 行為JAL/JALR 寫回 PC+4；JALR 目標清 bit 0。相同
記憶體裝置ROM、RAM、TextBuffer、Halt提供的 support/SRAM.v，分成 IM、DM今年不自行重做這些周邊，改接兩個 SRAM。不同
指定實例ZIP 有 core/program_counter/reg_file 等Top 內 PC、regfile、IM、DM大小寫要完全一致；不能任意更名。不同
記憶體參數獨立 ROM/RAM 模組IM READ_ONLY=1；DM READ_ONLY=0IM 不寫入，IM.halt 留空；DM.halt 接 Top.halt。不同
Load 類型LB/LH/LW/LBU/LHU相同五種signed 與 unsigned 延伸不可混用。相同
Load byte 定位ZIP ROM/RAM 從傳入 byte address 組合四 bytesTop 先對齊 word，再右移 8×offset，送 LD_Filter今年 LD_Filter 無 address，僅處理低位 byte/halfword 延伸。不同
Store 類型RV32I 目標包含 SB/SH/SW；ZIP 卻固定 1111明列 SB 0001、SH 0011、SW 1111固定 1111 是學生程式缺口，不代表 2025 只要求 SW。不同
Store laneZIP 直接傳 rs2_data 與有效位址Top 左移資料 8×offset，左移 mask offset今年必須用對齊位址、正確 byte lanes 寫入。不同
Halfword offset 12025 簡報未明文列出此驗收邊界明訂 offset 0、1、2 可用只要不跨 word；不能只支援偶數位址。資料不足
跨 word 與例外2025 現有資料未明文確認不測跨 word load/store，不需處理這類例外word offset 0；halfword 不含 offset 3。資料不足
終止機制ZIP Top 的獨立 Halt 裝置向 0xFFFFFFFB 寫入 byte 1，DM 產生 halt今年 termination store 也須通過正常 lane 位移；不需 ECALL。不同

互動示範｜2026 部分寬度存取與 byte lanes
選擇指令與 word 內 offset，觀察 SRAM 對齊位址、資料位移及 byte write-enable。預設有效位址為 0x1000＋offset，store source=0xA1B2C3D4，讀回 word=0x80FF7F01。這是計算示意，不是 RTL 模擬。
// 2026 Top 內的概念示意；請依官方骨架宣告實際訊號
assign dm_addr  = {effective_address[31:2], 2'b00};
assign dm_wdata = rs2_data << {effective_address[1:0], 3'b000};
assign dm_wmask = rst ? (basic_wmask << effective_address[1:0]) : 4'b0000;
assign shifted_load = dm_rdata >> {effective_address[1:0], 3'b000};
// shifted_load → LD_Filter → writeback
// basic_wmask: SB=0001, SH=0011, SW=1111；非 store=0000
// DM.halt 直接連 Top.halt；IM.halt 留空

例：SB offset 3 → mask=1000；SH offset 1 → mask=0110。終止 byte store 到 0xFFFFFFFB：對齊位址 0xFFFFFFF8、offset=3、mask=1000、write_data=0x01000000。
