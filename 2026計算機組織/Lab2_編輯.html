07題目一：Signed Array Sort

void array_sort(int32_t *array, uint32_t size);

a0 是陣列首位址；a1 是元素數量。每個元素 4 bytes，元素 i 的位址為 a0 + 4×i。size 為 0 時仍傳入有效對齊指標，但函式不應讀寫任何元素。

  1. size<2 直接返回。
  2. 從 i=1 開始，記住 key=array[i]。
  3. 前一元素若以 signed 比較大於 key，就右移一格。
  4. 找到插入位置後寫回 key，繼續下一元素。

例如 [3, −2, 3, 0] → [−2, 0, 3, 3]。數值比較用 signed 的 blt／bge；迴圈索引或數量比較要依 unsigned 語意處理。不可用 unsigned 比較排序負數。

檔名 merge.S 不代表強制 Merge Sort；不要求 stable sort，也不限定演算法。Insertion Sort 可作為容易驗證的實作。

08題目二：4×4 Sudoku

void sudoku_solver(int32_t *board);

a0 指向 row-major 的 16 個 int32_t，位址為 base + 4×(4×row+col)。0 是唯一空格值。輸入合法且至少有一解，不要求處理非法或無解輸入。

  1. 找出一個值為 0 的位置；若沒有空格，完成。
  2. 試填 1–4，逐一確認同一列、同一行與 2×2 宮格沒有相同值。
  3. 合法才寫入並往下一層搜尋。
  4. 後續失敗時，將自己試填的位置還原為 0。
  5. 找到合法解就返回，保留全部原始非零線索。

2×2 宮格起點：(row & ~1, col & ~1)。因 RV32I 沒有 M extension，索引乘 4 可用 slli；不要直接使用 mul／div／rem。

多解盤面接受任一合法解。遞迴 helper 可以有自己的內部成功旗標，但公開 sudoku_solver 是 void 函式。

09RV32I、ABI 與記憶體安全
規則實作注意
rv32i／ilp32允許展開為 RV32I 的 pseudo-instruction 與 assembler macro；不用 M／F／C extension
s0–s11使用前保存，返回前還原
gp、tp不得破壞
sp執行期間 16-byte 對齊；返回前還原原值
ra若呼叫 helper／遞迴會覆寫返回位址，先保存自己的 ra
a0–a7、t0–t6caller-saved；跨呼叫仍要用的值由 caller 保護
記憶體只存取輸入陣列、自己的合法資料及 stack；word 存取對齊 4 bytes
組合語言來源直接送 GNU assembler，不使用 C preprocessor；禁止 .include／.incbin
外部 symbol唯一允許的 runtime symbol 為 my_printf；兩題均不需它

可採 16、32、48… bytes 的 stack frame。需依實際保存的暫存器設計；不能每次遞迴只減 4 bytes 而破壞對齊。
