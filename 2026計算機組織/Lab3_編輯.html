按照既有順序，一步一步完成課程環境、個人專案下載、九個模組實作、七項驗證、報告、提交與備份。每段都標示執行環境、指令、完成判準與排錯方法。

完整操作順序

01啟動或安裝 WSL 2Windows PowerShell（首次安裝用系統管理員）

已有 Lab 1／Lab 2 環境可直接檢查，不必重新安裝。首次安裝後重新啟動 Windows，再開 Ubuntu 建立 Linux 帳號與密碼。

# 安裝並重開機後：

完成判準：Ubuntu 列於清單，VERSION 為 2；最後進入 Linux shell。密碼輸入時沒有星號是正常現象。

遇到問題：若發行版名稱不是 Ubuntu，使用清單中的實際名稱。VERSION 為 1 時可在 PowerShell 執行 wsl --set-version Ubuntu 2。BIOS 虛擬化未啟用需先啟用。

07設定 Git 身份與 SSHDocker 容器

SSH 金鑰須在實際執行 Git 的環境可用。若原容器已能連 GitHub，保留既有設定，不重建。新建金鑰時設定密碼並妥善保留。

git config --global user.name "YOUR_NAME"
git config --global user.email "YOUR_GITHUB_EMAIL"
ls -la "$HOME/.ssh"
# 僅在沒有可用金鑰時執行；不要覆寫現有檔案
ssh-keygen -t ed25519 -C "YOUR_GITHUB_EMAIL"
eval "$(ssh-agent -s)"
ssh-add "$HOME/.ssh/id_ed25519"
cat "$HOME/.ssh/id_ed25519.pub"

完成判準：複製 .pub 公開金鑰，在 GitHub → Settings → SSH and GPG keys → New SSH key 新增 authentication key。

遇到問題：不要複製 id_ed25519 私鑰。WSL 的 ~/.ssh 與容器的 ~/.ssh 不一定相同。新 shell 若 agent 不在，重新啟動 agent 並 ssh-add 即可。

九個模組：編輯內容與完成目標

檔案（rtl/src/）實作與檢查重點
Reg_PC.v低有效非同步 reset；每個上升緣載入 next_pc，不能沿用 first_cycle 停拍。
RegFile.v兩組組合讀、上升緣寫；32 個暫存器 reset 為零，x0 永遠為零；registers 名稱固定。
Decoder.vopcode=inst[6:2] 是 5 bits；func7=inst[30] 是 1 bit；輸出 rs1、rs2、rd、func3。
Imme_Ext.v由指令本身辨識 I/S/B/U/J，正確重組與延伸；B/J 最低 bit 補零。
ALU.v加減、邏輯、位移、有號／無號比較及分支 jump；位移量取低 5 bits。
JB_Unit.v計算 PC 或 rs1 加上立即數的目標；Top 處理 JALR 目標最低 bit 清零。
LD_Filter.v輸入是 Top 位移後的資料；實作 LB/LH/LW/LBU/LHU 的符號／零延伸。
Controller.v每條指令控制訊號與預設值完整，避免 latch；store 不寫 rd，非 store 不寫 DM。
Top.v整合 PC/regfile/IM/DM；PC+4 寫回、資料 mux、位址對齊、byte offset、移位遮罩、reset 禁寫及 DM.halt。

今年是單週期 CPU；IF、ID、EX、MEM、WB 是同一週期中的概念步驟。不要加入五級管線或沿用去年的 BranchComp／CoreTop 外層介面。

七項測試與實際執行檔

CTest 名稱配分+prog_elf_path 的路徑主要觀察方向（教學說明）
print_test5build/runtime/test-progs/print輸出／MMIO、基本流程
msort_test10build/runtime/test-progs/msort遞迴、stack、load/store
qsort_test10build/runtime/test-progs/qsort比較、分支、排序
matmul_test10build/runtime/test-progs/matmul迴圈、陣列位址與運算
malloc_test_test10build/runtime/test-progs/malloc_test動態配置與記憶體
isa_edges_test20build/tests/isa_edges.elf指令邊界、有號／無號、跳躍
partial_access_test15build/tests/partial_access.elfbyte/halfword 的 offset、遮罩與延伸

程式共 80 分，報告另計 20 分。測試的觀察方向不是完整覆蓋保證；最終以今年 TA 環境評分為準。

部分存取：整合 Top 時的檢查

操作Top 的處理驗收要點
Loaddm_addr = effective_addr & 0xFFFFFFFC；dm_rdata 右移 8×offset 後送 LD_FilterLB/LH 符號延伸；LBU/LHU 零延伸
Store資料左移 8×offset；SB/SH/SW 基本 mask 為 0001/0011/1111，再左移 offsetSB offset 3 → 1000；SH offset 1 → 0110
邊界與 resetbyte offset 0–3；halfword 0–2；word 0halfword offset 1 必須支援；reset 與非 store 的 wmask=0
HaltDM.halt 直接接 Top.halt透過正常 store 路徑終止；不自行實作 ECALL
