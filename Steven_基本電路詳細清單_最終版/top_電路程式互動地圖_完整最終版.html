總覽｜top 的功能、電路與面積

本檔案共 139 行，整理 71 個可選取的電路與連線觀察項目；功能可能重疊，不等於實體電路數。點選兩側清單，程式碼、電路說明及標準元件會同步更新。

合成後標準元件數與面積，必須依完整設計、library、約束與合成報告確認。本頁試算是可調整的教學示例，不能將不同功能項目的數值相加。

top.sv 引用多個子模組；單靠 top.sv 無法確認各模組內部功能或完整 CPU 的合成面積。必須提供並核對相容版本的所有子模組。

範例 1｜共用資料記憶體忙碌條件

左視窗｜原始碼與原始行號

＋ 新增位置：在原第 30 行之後、module 內新增 mem_active 的宣告與連續指定。
30 logic branch_taken,redirect,mem_hold,can_advance,fetch_ok;78 assign dm_req=mv&&(mload||mstore_en)&&!mem_sent;90 assign mem_hold=mv&&(mload||mstore_en)&&!(mem_sent&&dm_valid);

右視窗｜修改後程式碼

// 新增在 module 層（例如原第 30 行之後）
logic mem_active;
assign mem_active = mv && (mload || mstore_en);

// 取代原第 78、90 行
assign dm_req   = mem_active && !mem_sent;
assign mem_hold = mem_active && !(mem_sent && dm_valid);

基本電路、標準元件與面積

原本兩條式子都包含 mv && (mload || mstore_en)。若合成器沒有共用，可以共用 OR 與 AND 的判斷，可能減少重複邏輯與對應的 cell。共享也可能增加負載並插入 buffer；工具也可能本來就已共享，因此面積不一定變小。

驗證方式：比較 mv、mload、mstore_en、mem_sent、dm_valid 的全部二態組合，並以模擬檢查 X/Z、記憶體延遲及 dm_req 單次脈衝；保持原本握手週期。

基本電路、標準元件與面積

原第 127 與 128 行重複相同的三個控制條件。明確共用後，可能減少重複 NOT、AND 或複合閘；但這是常見的合成器自動最佳化，面積也可能完全不變，或因扇出和時序而變大。

驗證方式：比較 dv、load_bubble、redirect 所有二態與 X/Z 情況；在 clock 穩定前完成組合傳播，驗證 stall、load bubble、redirect 和管線 valid 更新。

範例 3｜共用 MEM 端可轉送條件

左視窗｜原始碼與原始行號

＋ 新增位置：在原第 30 行之後、module 內新增 mem_forwardable 的宣告與連續指定。
30 logic branch_taken,redirect,mem_hold,can_advance,fetch_ok;43 if(mv&&mwf&&!mload&&mrd==er1) ea=mres;45 if(mv&&mwf&&!mload&&mrd==er2) eb=mres;49 if(mv&&mwi&&!mload&&mrd==er1) ea=mres;53 if(mv&&mwf&&!mload&&mrd==er2) eb=mres;56 if(mv&&mwi&&!mload&&mrd==er2) eb=mres;

右視窗｜修改後程式碼

// 新增在 module 層（例如原第 30 行之後）
logic mem_forwardable;
assign mem_forwardable = mv && !mload;

// 以下為各行的替代寫法：其餘原程式和 else if 均保留
// 原第 43、45 行
if (mem_forwardable && mwf && mrd==er1) ea=mres;
if (mem_forwardable && mwf && mrd==er2) eb=mres;
// 原第 49、53、56 行分別替代
if (mem_forwardable && mwi && mrd==er1) ea=mres;
if (mem_forwardable && mwf && mrd==er2) eb=mres;
if (mem_forwardable && mwi && mrd==er2) eb=mres;

基本電路、標準元件與面積

五處條件都包含 mv 和 !mload；如果未被合成工具共享，抽取成共同條件可能減少重複反相及 AND 邏輯。比較器、整數／浮點來源及 MEM 優先於 WB 的選擇不能刪除；共享扇出或時序限制也可能抵消面積節省。

驗證方式：各行原位置替換，保留所在 if／else if 結構。測試整數及浮點轉送、MEM/WB 同時符合時的優先權、load 未完成與 er1/er2 相等情況，並做時序模擬或等價檢查。

比較方法：補齊相容的子模組，以相同 library、工具版本、時序／負載約束合成前後版本，核對功能、cell 數、Total cell area 與時序。節省率 =（原面積 − 修改後面積）÷ 原面積 × 100%；不能以程式行數推斷面積。
