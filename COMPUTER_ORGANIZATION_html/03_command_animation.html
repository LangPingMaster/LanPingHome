DOCKER第 6／22 步

首次建立 ED25519 SSH 金鑰

DOCKER · 只複製這一條命令
ssh-keygen -t ed25519 -C "E24144773 GitHub"

這一步怎麼做

只限全新容器且目前沒有金鑰時執行。你的附件已顯示建立成功；若使用同一個容器，直接按下一步。儲存位置按 Enter；密碼片語可自行設定，留空時連按兩次 Enter。若問 Overwrite，先停止，不要覆蓋。

完成後應看到

私鑰在 /home/ubuntu/.ssh/id_ed25519；公鑰在 /home/ubuntu/.ssh/id_ed25519.pub。

DOCKER第 7／22 步

顯示並複製完整公鑰

DOCKER · 只複製這一條命令
cat ~/.ssh/id_ed25519.pub

這一步怎麼做

複製輸出的一整行：ssh-ed25519 開頭、E24144773 GitHub 結尾。只需分享 .pub 公鑰，勿分享沒有 .pub 的私鑰。

完成後應看到

終端機印出一行 ssh-ed25519 AAAA… E24144773 GitHub。

GITHUB第 8／22 步

在 GitHub 帳號加入 SSH 公鑰

開啟 GitHub SSH keys 設定頁 ↗

這一步怎麼做

在 Windows 瀏覽器登入 E24144773，進入 SSH and GPG keys → New SSH key。Title 可填 CO Lab1 Docker；Key type 選 Authentication Key；Key 貼上上一頁的整行公鑰；按 Add SSH key。既有相同金鑰可直接略過。

完成後應看到

SSH keys 清單中出現你的 Authentication key。

DOCKER第 9／22 步

這一步怎麼做

首次提示主機指紋時，先跟 GitHub 官方資料核對；相符後輸入完整 yes。只輸入 y 不夠。

完成後應看到

Hi E24144773! You've successfully authenticated, but GitHub does not provide shell access.

WSL第 20／22 步

從 Docker 複製到 Windows E 槽

WSL · 只複製這一條命令
docker cp comporg_Lab1-dev-container:/home/ubuntu/workspace/fall-2026-lab1-e24144773 /mnt/e/GitHub/CO/Lab1/

這一步怎麼做

整條命令必須是一行。冒號前為容器名，冒號後為容器來源；最後為 WSL 對應的 Windows E 槽。

完成後應看到

Successfully copied 183kB to /mnt/e/GitHub/CO/Lab1/（大小可能變動）。
