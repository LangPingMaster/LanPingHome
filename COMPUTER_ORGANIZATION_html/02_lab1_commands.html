四、首次準備、編譯、測試

以下全部在容器內的專案根目錄執行。每行完成後再輸入下一行；看到錯誤時先處理，不要直接繼續。

cd /home/ubuntu/workspace/fall-2026-lab1-e24144773
git submodule update --init --recursive
pre-commit install
make -C riscv-tests/isa -j
ls -l riscv-tests/isa/rv32ui-p-add
cmake -S . -B build
cmake --build build --parallel
ctest --test-dir build -N
ctest --test-dir build --output-on-failure
指令目的與預期結果
git submodule update --init --recursive下載 riscv-tests 與巢狀子模組；首次及子模組缺失時使用。
pre-commit install安裝提交前檢查；每個 clone 做一次。
make -C riscv-tests/isa -j建立 RISC-V ISA 測試用可執行 ELF；新的 clone 必做一次。
ls -l riscv-tests/isa/rv32ui-p-add確認 add 測試檔存在，避免後續 load_elf 找不到檔案。
cmake -S . -B build建立 CMake 設定；初次或設定變更時執行。
cmake --build build --parallel把目前 C 程式重新編譯成可測試執行檔。
ctest --test-dir build -N列出測試名稱，不真正執行。
ctest --test-dir build --output-on-failure執行完整測試並顯示失敗原因。

你的紀錄中曾先執行 CTest 才建置 riscv-tests/isa/rv32ui-p-*，因此發生 load_elf: Assertion 'f != NULL' failed。上面的順序已修正此問題。後段紀錄出現 37 項測試通過，這是該次終端紀錄的結果，不保證之後修改程式仍全部通過。

只測一項，方便除錯

ctest --test-dir build -R '^OP_add$' --output-on-failure --timeout 10

^ 和 $ 限定完整測試名稱。測試卡住時可使用 --timeout 10。若名字不確定，先執行 ctest --test-dir build -N。

五、修改程式後，怎樣讓測試使用最新版本？

編輯並儲存 src/core.c 後，回到容器內專案根目錄，重新編譯，再執行測試：

cmake --build build --parallel
ctest --test-dir build --output-on-failure

只改 report.md 時不需要為了報告重新編譯。編譯失敗時會繼續保留舊執行檔，不能把舊測試結果當成新程式通過；確認 cmake --build 成功後再測。首次測試 ELF 已建立後，普通程式修改不必每次重新執行 make -C riscv-tests/isa -j。若要更改 CMake 設定，再先執行 cmake -S . -B build。

六、檢查並繳交

完成 src/core.c 與原有 report.md，確認姓名、學號及題目答案，測試通過後在容器內專案根目錄執行：

git status
git diff -- src/core.c report.md
git add src/core.c report.md
git commit -m "feat: complete Lab 1 ISS"
git status --short -- src/core.c report.md
git push

若 pre-commit 自動修改檔案並中止 commit，先檢查 git diff，再執行 git add src/core.c report.md 和 git commit -m "feat: complete Lab 1 ISS"。不要略過檢查。git status --short -- src/core.c report.md 無輸出表示這兩個檔案沒有未提交修改；git push 成功後，到 GitHub 和 Classroom50 查看該提交的評分結果。根據課程 Lab 1 說明，每次 push 到預設分支都會觸發提交與自動評分，無須另外上傳 ZIP 到 Moodle，也不需要建立提交 tag。

後續再改程式時，依序：存檔 → 重新編譯 → 測試 → git add → git commit → git push；沒有新 commit 就不會將你的新修改送上去。
