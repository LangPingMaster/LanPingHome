數字說明：146 項是各頁基本電路與連線觀察項目的合計，項目彼此可能重疊，且包括介面與設計觀察；並非實際基本電路的數目。實際標準元件總數、面積無法僅由 RTL 判斷，須使用完整設計、目標 library 及合成報告。

模組與可能電路

模組主要工作教材項目可能涉及的電路
top
CPU 頂層		連接取指、解碼、執行、記憶體和寫回階段及其控制。11模組連接、介面邏輯；加法、MUX、控制閘；解碼、暫存器、轉送、ALU；暫存器、MEM 邏輯、MUX；控制邏輯、CSR 計數與選擇
IF
取指階段		在同步重設與啟用控制下更新 PC，輸出指令位址。3同步 reset DFF、enable MUX；接線、實作上可能含緩衝
ID_reg
取指到解碼暫存		追蹤 pending，接收指令資料並處理 valid 和 redirect。5同步 reset DFF、enable、pc−4 邏輯；valid DFF、控制邏輯
ID
解碼階段		擷取指令欄位、產生控制與立即數，連接整數和浮點暫存器檔。8接線、opcode 解碼、選擇；接線、符號延伸、MUX；記憶體或 DFF、讀取 MUX
EX_reg
解碼到執行暫存		儲存 EX 資料與控制，處理有效位、bubble 和 redirect。5同步重設 DFF、選擇器；使能、valid DFF、控制閘
EX
執行階段		選擇運算元、處理轉送，連接 ALU 與分支跳躍模組。10opcode 解碼、MUX；比較器、優先 MUX；比較器、解碼、MUX；ALU、比較、加法與連線
ALU
算術邏輯單元		執行算術、位元、移位、乘法及浮點結果選擇。31乘法、減法、條件選擇；浮點運算、選擇；MUX、加法器；加減、比較、MUX；解碼、移位、OR、MUX；比較、MUX、移位、邏輯閘；優先偵測、加法與選擇；加減、比較、位移、邏輯及 MUX
MUL
整數乘法		按 OP 選取低位、高位及四路點積運算。8乘法器及部分乘積網路；乘法、條件選擇、減法；乘法及符號處理；四組乘法與加法
FPU
浮點運算		按 OP 選擇加減或最小最大值，觀察對齊與捨入。16參數化浮點運算電路；比較、減法、MUX、移位、OR；加減、迴圈展開邏輯、移位；AND/OR、加法、MUX；比較、MUX；可能有內部 latch
JB_unit
分支與跳躍		進行分支比較並計算跳躍目標位址。7加法器、解碼、MUX、遮罩；比較器、解碼、MUX
MEM_reg
執行到記憶體暫存		保存 EX 結果與控制，追蹤記憶體請求狀態。6同步 reset DFF、MUX；DFF、使能與優先選擇；opcode 比較與 32-bit MUX
MEM
記憶體存取		處理讀取擷取、寫入遮罩、資料選擇及等待。11移位器、選擇器；比較器與 32-bit MUX；控制閘、選擇與連線；移位、NOT、MUX、解碼
WB_reg
寫回暫存器		保存寫回資料、目的地址、控制訊號與有效位。4同步 reset DFF、選擇邏輯；DFF、enable MUX
WB
寫回介面		將資料與寫回控制訊號連接到對應輸出。1主要為接線；負載可能需要 buffer
Controller
控制與 CSR		產生取指、推進、重新導向，並提供 CSR 計數與選擇。11NOT、AND、OR、複合閘；OR、AND、NOT；64-bit DFF、加法器、enable MUX；地址解碼與 MUX
Regfile
整數暫存器檔		提供兩個讀取埠及寫入邏輯，x0 讀取為零。5儲存陣列、讀取 MUX、x0 比較；寫入解碼、DFF 或記憶體
Regfile_F
浮點暫存器檔		提供浮點雙讀取與寫入，浮點暫存器 0 可寫。4儲存陣列、雙讀取 MUX；寫入解碼、DFF 或記憶體
表中類型是概念對應，不是實際合成 cell 清單；cell 面積與個數需由 netlist 和 .lib 確認。
